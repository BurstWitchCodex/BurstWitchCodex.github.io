#### 【导师大人亲启：】（key 9941）

#### 【导师大人亲启：】（key 9942）

在与你相遇之前的我，明明早已做出了决定。

无论幽暗尽头是什么，那决心本都不该有所动摇。

然而太阳升起，即便是那仅剩绝望的深渊，也出现了摇曳的海市蜃楼。

也许正是从那时起，我理解了世人为何惧怕老去与死亡。

因为在那时间无涯的荒野中，光明就这样出现在了面前，任谁都不会忍心放手。

时常在月夜里彷徨徘徊，假装是在寻找明天。

这些深埋在内心的疑惑，也许只有你能给予解答。

夜莺之庭的寂静，希望你会喜欢。顺便，也想赠你一份谢礼。
#### 【导师大人亲启：】（key 9943）

冬去春来，夜莺森林的雪花初融之际，诺塞司大陆也将迎来二月的节日。

我很早以前就知道这个节日，但也只是限于知道的范围，毕竟从前的我并没有想要与之共度此日之人。

但从今年开始就不一样了，这份欣喜，这份鼓动，都是因为你来到了我的身边。这一天对我而言，再也无法与其他的平凡每日对等——你的存在为它赋予了特殊的意义。

霜雪冰冷而坚硬，可以摧毁犯境敌者，但同时它也脆弱不堪，只需你用手轻触，它就愿意被你的体温融化至再无棱角。

所以，你愿捧起随信一同到的的那朵霜花吗？那是我真正的邀请函，它不畏惧一切高温锐物，唯独你的温度才可将它消融。我知道它的状态，也会知道你的选择。

我即是冰雪。你可愿意来赏一场，我只想为你一人呈现的雪景？
#### key 9951

假日将至，导师在玛丽的安排下带着十名魔女，跟着安息日马戏团的安格莉卡前往观演马戏。

未曾想在路上碰到了四处乱跑的玩偶。看到它们的安格莉卡露出了惊慌的神色。
#### key 9952

来到安息日马戏团的驻扎地，帮助团长玛蒂尔达将剩余的玩偶捕捉后，魔女一行进入马戏团帐篷准备观看演出，马戏团却突生异变。
#### key 9953

魔女们被空间魔法所分散，导师一行捡到了条目有些诡异的守则，还遭到更加凶暴化的玩偶与魔兽袭击。
#### key 9954

神秘的女孩年出现在了导师一行的面前，带来更加扑朔迷离的现状后就逃走了。

想要追击却遭到了突然出现的玛蒂尔达的阻拦——她的精神被控制了！
#### key 9955

将玛蒂尔达恢复后紧接着是偷偷跟来的安娜，不过她自行解除了精神控制，并带来了第三张守则。

继续前行的众人发现，马戏团内又出现了微妙的变化。
#### key 9956

与年长得一模一样的夕正是引起马戏团骚动的元凶，可她一心扑在寻找年上，并不理会其他，也不愿意解除对马戏团的控制。
#### key 9957

洛菲莉尔叙说了异界的传说故事，为众人打开了新的思路。

追寻着夕的踪迹最终找到的却是年——导师有了个大胆的猜测。
#### key 9958

年与夕一体双魂，因此无法相见。

在导师的努力下，姐妹的魂魄得以暂时分离，终是得以团聚，后随众人一同前往夜莺城堡，共同度过了一个美好的夜晚。
#### key 9961

魔女一行受邀来到海尔拉姆参加霜祝庆典，但典礼却因故推迟，突如其来的暴风雪把所有人困在了此处，至此众人决定展开调查，解决危机。
#### key 9962

根据斯露德提供的线索前往英灵殿调查，路上遭遇的古神卡尔娅行为令人不明所以，只能继续前行。

在更深处的道路上发现了祭司，然而这并不意味着危机解除。

深层真相仍待探寻。
#### key 9963

昏迷的祭司并无大碍，只是被魔咒所困，需由施咒人解除才能令其苏醒，根据其备忘录信息，众人展开了调查。

被列为头号嫌疑人的是那个眼熟的家伙。
#### key 9964

下一个目标为海尔拉姆郊外的墓园，因魔物们暴动，对海尔拉姆的守护屏障展开冲击，将优先事项变更为击退魔物。

一只使魔在战斗过程中悄无声息地攀上了导师的脖颈……
#### key 9965

陌生的少女守在墓园前，阻止着所有人进入墓园，甚至要对硬闯之人诉诸武力。

同为外来者，她的动机是什么？
#### key 9966

现有线索无法构成完整证据链，前往发现祭司的现场寻找遗漏线索——无法参透的话语，尽全力想要避开的对象，无法自由行动的意志……

在二度踏足之前，这是未曾设想过的情景。
#### key 9967

骤然扩大的危机，自内部迅速蔓延的灾害，前往一切源头之地，被奉为北境之主的古神所做之事令众人瞠目结舌。
#### key 9968

灾厄的抑制只是暂时，然而现在便暂且放下无边的忧虑，放松享受欢欣喜悦的庆典即可。
#### key 9971

夏伦重伤于河岸边，险死逃生的她曾经经历一场恶战，那是一支组成混杂的队伍，既有敌人，也有曾经的友军。

如今，夏伦濒死，但希望并未断绝，一个神秘的身影出现在她面前，令其伤势痊愈的同时，更获得了新的力量。
#### key 9972

雄伟的王城，却弥漫着异样的气息，黑暗中的幽影，神秘的少女竟是王室旁系。

夏伦归来发现王城内早已充满异常，护卫军擅自行动，更有魔物涌现，大肆骚扰。夏伦和夏洛特因相近的目的而达成共识，暂且共同行动。
#### key 9973

为确保王储特蕾莎的安危，夏伦直闯寝宫，却遭到了珊蒂娜率领的护卫军阻拦，双方各执一词，立场不和，战斗一触即发。

然而此时的珊蒂娜已经感染了瘟疫，并不是已经转化为血族的夏伦的对手。

在将珊蒂娜制服并控制住护卫军后，夏伦前往查看特蕾莎的情况，却发现寝殿之内空无一人。
#### key 9974

同一时刻，永夜帝国的一处小镇边缘，来自外乡的一支骑兵队正在夜色下疾行，他们绑架了生命垂危的王储特蕾莎，似乎准备逼问一些想要的情报。

然而，一个娇小的身影出现并阻挡在了他们的面前，仅仅一个照面，便有骑士直接身亡，剩下的虽然人数众多，但无关人数，面对传说，他们仅仅只是蝼蚁罢了。
#### key 9975

夏洛特依靠潘恩的嗅觉成功找到了特蕾莎，而周围则是刚才企图掳走特蕾莎的那些神秘骑士的尸体，没人知道这些骑士究竟因何而亡。

而特蕾莎，则在经过检查后发现其身染的瘟疫已经痊愈，虽然不清楚究竟发生了什么，但当务之急是带特蕾莎回到王城。

而就在此刻，大量的魔物从周围显现，这些本不该出现在永夜帝国境内的怪物，向着夏洛特、特蕾莎，还有驰援而来的施密特亲卫发动了攻击。
#### key 9976

涌现的魔物并没能阻挠特蕾莎等人的脚步，成功返回王城后，特蕾莎遇到了一波民众，而从他们惊恐的反应中得知，有人泄露了贵族染病的消息，并散布了新的谣言，更有一支圣摩拉的部队出现在此地，试图将特蕾莎与夏洛特两人绑走。

在僵持过后，特蕾莎等来了夏伦的援军，圣摩拉部队难以支撑只能选择撤退。

众人汇合后根据现有情报进行推算，认为一切的祸首，极有可能便是宰相海因兹。
#### key 9977

集合了现有兵力，准备展开反击的特蕾莎率领部队来到了海因兹所在的广场。

面对摆在眼前的证据，民心很快便回到了特蕾莎一方，海因兹的计谋没能得逞，只能祭出手上隐藏的王牌，召集了从圣摩拉带来的部队，希望由他们通过武力控制住特蕾莎她们。

而这支部队的领袖，便是与珊蒂娜相识的伊斯特尔。一面是自己效忠的君主与国家，另一面则是养父与相识的好友。

珊蒂娜面对这样的局面，依然坚定地拔出武器，最终击败伊斯特尔，为特蕾莎开出道路，直面最后的敌人——海因兹。
#### key 9978

没有了任何援助的海因兹此刻已经穷途末路，他没有其他的选择。为了能够扭转局面，他选择动用了与恶魔交易得来的力量。

虽然借用恶魔的力量，海因兹一度占据上风，但在伊丽莎白现身之后，一切的抵抗都成了徒劳，面对永夜之神的力量，海因兹的抵抗根本微不足道。

但即便如此，海因兹也想要拉上特蕾莎共赴黄泉。然而却被夏洛特以身挡下。

最终，海因兹的叛乱被平息，本该死去的夏洛特也被伊丽莎白转化为了血族，特蕾莎登基，而经历过这一役的所有人，也有了各自新的选择。
#### key 9981

夜莺城堡突遭震动，导师从妮蔻拉丝那里得知茉门是起因。

两人一同前往茉门处，遭到了暴动魔物的袭击。
#### key 9982

得知娃娃洁恩体内有着被茉门封存于其中的灵魂，在妮蔻拉丝的请求下导师将其保护起来，不料遭到魔力反扑。
#### key 9983

导师一行在魔力的影响下看到了映照过往的海市蜃楼，并得知茉门原是孤儿院的执誓，很受孩子们欢迎。

斯温德勒执誓带来了一位自称是贵族管家的领养人，但却被茉门揭穿他是个骗子，没让他带走孩子，领养人悻悻而归。
#### key 9984

茉门去采购物资，镇上的人对茉门发出各种恶意的猜测，茉门并不理会这些流言，遭到他人推搡之时被导师的魔力救下。

晚上茉门哄孩子们睡下之后正要休息，为她端来热茶的斯温德勒执誓显出了阴险的神情。
#### key 9985

孤儿院燃起大火，茉门视力受损看不清现场，不知孩子们已经全部死亡，仍在寻找他们，并请求斯温德勒执誓帮忙，却得知他正是纵火的元凶、孩子们已经全部遇难。

悲愤的她爆发魔力，将罪魁祸首消灭，并将孩子们的亡灵缝合封存在了娃娃体内。

另一方面，导师与妮蔻拉丝也将返回现实。
#### key 9986

现实中的茉门因洁恩躯体被破坏而陷入狂乱，在导师与妮蔻拉丝将其安抚下之后，又帮助她将娃娃修复并将灵魂重新封存于娃娃躯体内。虽然过程中发生了茉门魔力不足的状况，但是最终成功完成。

夜莺森林的异变停止，茉门也不再疯狂绝望，一切都回到了正轨。

然而在离开之际，导师注意到了洁恩的面容上浮现出了诡异的笑容。
#### key 9991

魔女为拯救被梦魇所困的雅努西娅进入其梦境，出现在神庭天狱，遇到守狱神使，开战。

#### key 9992

魔女在天狱走廊搜寻雅努西娅的身影，听到基露卜的歌声，得知雅努西娅竟然就是德维娜。

原来德维娜因守护帕拉迪斯不力被判堕天，阴差阳错成为了后来的雅努西娅。同时得知神庭要引洪水灭世。

魔女前往人间追寻雅努西娅。
#### key 9993

魔女在恶魔手中救下了卡尔，和卡尔进行了对话。

魔女询问卡尔是否见到一个银发小女孩，卡尔反问那个女孩是雅努西娅吗？他认识，魔女们十分惊喜。

#### key 9994

#### key 9995

#### key 9996

血月状态的雅努西娅以为是卡尔背叛了自己，认为人类都是不可饶恕的原罪，要毁灭伊诺森特之舟。n

一切终结，梦境崩塌，魔女回到了现实。
