# 二、支线与角色外传

#### key 1011

领受玛丽命令的蔷薇骑士团准备在圣摩拉展开魔女营救行动，救出被关入伊迪斯地牢的魔女。

塞布丽娜先行潜入地牢查探情况，西莱斯特与嘉萝琳则假借骑士团与海因里希之名顺利混入地牢。

可惜刚进入之时就遇上了地牢戒备的紧急情况，不得已与守卫阿道夫展开战斗。
#### key 1012

进入地牢的三人汇合后发现地牢中空荡得不可思议。

正当她们对此进行讨论之时，骑士威尔匆匆赶来，试图向还在前线的海因里希传递这边的信息，蔷薇骑士团三人必须拦下他。
#### key 1013

继续往深处探索之时，蔷薇骑士团遭遇偷袭。

从用以袭击的匕首来看是星辰之环的人，双方不由分说地展开了战斗。

塞布丽娜认出了来人，是她以前认识的莎娜，双方停手，发现目标一致，决心连手一起解救无辜的魔女。
#### key 1014

看守威尔马的是一个暗影骑士，西莱斯特将其引走让另外三人救出威尔马。

威尔马受伤较重，需要一段时间才能恢复，嘉萝琳担忧西莱斯特的安全，三人商议过后由莎娜留下照看被治愈法阵治疗中的威尔马，嘉萝琳与塞布丽娜前去寻找西莱斯特。
#### key 1015

正要悄悄返回的西莱斯特遇上了一个神秘的轻佻男子，他还向她打听名为斯露德的人的牢房信息。

西莱斯特找准时机逃离了他的劫持，并与后来的嘉萝琳与塞布丽娜共同对阵，然而还是落在了下风。

此时莎娜赶到，说明男子——约翰亚斯也是友军。

顺利找到了斯露德，约翰亚斯与莎娜带着她先行离开了地牢。
#### key 1016

暗影骑士发现斯露德被救走，对蔷薇骑士团产生怀疑，要将她们交给海因里希定夺，蔷薇骑士团与其开战。
#### key 1017

昔日友人谢雅努斯揭穿了蔷薇骑士团的谎言，他虽对魔女没有恶意，但他坚定自己的圣摩拉立场，对三位魔女宣战。

最终在她们的请求以及昔日旧情的份上，他刺伤自己为她们制造机会，但从此他们也是彻底的敌人，从前的情谊已经荡然无存。
#### key 1018

三人成功救出提莉雅，嘉萝琳决意留下断后，让西莱斯特与嘉萝琳带着提莉雅先行离开，西莱斯特十分担忧却也无可奈何。

嘉萝琳抵挡大量增援将近力竭之时，她最害怕碰上的海因里希出现，并与她单独展开对决。

嘉萝琳并不是海因里希的对手，但海因里希没有杀她，与她进行最后一番谈话之后，海因里希放走了她。
#### key 1021

耀皇罗德里戈为了获得神使的回应而前往了巴贝塔，却只在残破的塔上遇到了恶魔和魔物。

连身上唯一保护了他一路的圣物，都在这里耗尽了最后的信仰之力。

别无选择的罗德里戈被迫与但他林所化的安迪进行了对话，却也因为这个决定，最终被但他林一步步拨开了受绝望侵蚀而碎裂的信仰，内心的动摇被一语道破。

最终，两人达成了协定。
#### key 1022

执行完任务回到圣摩拉城中的约翰亚斯决定前往酒馆消遣，遭到了莎娜的阻止，但最终还是被约翰亚斯说服，两人一同前往酒馆。

在这个混乱喧嚣的地方，鱼龙混杂，来自什么地方的人都有，同时……这里也是最适合获取情报和信息交流的地方。

约翰亚斯一边用各种理由拉着莎娜喝酒，同时也发现了最近城中出现的异样，以及一个被腐化成魔物的男子。

从他身上，约翰亚斯得到了与地牢和耀皇有关的情报。
#### key 1023

根据酒馆中获得的线索，约翰亚斯独自来到了地牢，并发现了恶魔信从踪迹。

解决掉对方后，约翰亚斯也发现线索牵引的矛头进一步指向耀皇罗德里戈。
#### key 1024

刚结束探查，约翰亚斯却发现莎娜也跟了进来。

交谈中，两人偶然发现了前耀皇嘉波并未身死，而是被囚禁在伊迪斯地牢中，此刻正用工具企图凿墙越狱。
#### key 1025

从意外发现的嘉波身上，两人获得了更多的情报，也明确了耀皇已经或主动或被动的与恶魔产生了来往。

为了确保圣摩拉民众的安危，约翰亚斯决定采取进一步的行动，但为了莎娜的安全，给她安排了另外的任务，两人重新将越狱未遂的嘉波囚禁起来后，便分头开始了各自的行动。

耀会里忠诚于耀皇的人非常多，其中也不乏能力高强的人，除海因里希之外，还有名为赫莎的魔女。

但不同于海因里希，赫莎有着冷静的分析能力，约翰亚斯权衡利弊，决定先与赫莎协商会见耀皇查明真相的事，以免之后两人产生不必要的冲突。

同时约翰亚斯也需要有赫莎这种程度的帮手，来帮自己在行动的过程中处理一些其他的事情。
#### key 1026

成功说服赫莎不站在自己的对立面之后，赫莎按照约定前往耀皇所在的耀堂附近。

果然发现了擅自行动准备来帮忙的莎娜，并在确认对方身份后佯装要去告发，以此将莎娜引走。
#### key 1027

这是最后的确认，也是最后的防线。

约翰亚斯抛开顾虑，独自前往耀堂附近，找到了亲自领兵守卫耀堂周边的卡琳娜。

一番交谈后，彻底确认了耀皇已经与恶魔勾结，而非遭到引诱和欺骗。

但同时也被敏锐的卡琳娜发现了破绽，约翰亚斯只能将计就计，趁着骑士长海因里希还未归来，将卡琳娜和一众护卫引诱至通往城外的方向。
#### key 1028

完成了所有准备，约翰亚斯最终站在了耀皇罗德里戈的面前，只不过现在的他，已经不再是星辰之环的团长。

而面对约翰亚斯的质问，罗德里戈也抛出了自己的见解，面对如此的绝境，两人都有自己的看法和坚持。

事已至此，双方都没有退路，只能选择用战斗的方式一决胜负。

然而，在双方的战斗见分晓前，骑士长海因里希已经赶回了现场，这场对决只能草草收场。

约翰亚斯留下了最后的忠告，无奈地选择了离开圣摩拉。
#### key 1031

妮蔻拉丝与西格莉德接受玛丽的最终试炼。

玛丽询问二人外出的理由，妮蔻拉丝称得到了有关她们姐姐——死神摩耳塔的信息，因此要出世寻找。

临行前，玛丽给予魔女们向自己提问一次的机会。
#### key 1032

到达圣摩拉的两位魔女苦于线索中断。

目睹命案，遭遇栽赃，脱险后在前辈薇泽尔的帮助下，取得了新线索。

两人继续踏上旅程。
#### key 1033

魔女一边寻找前往深渊之路，一边讨论着各自对玛丽提出的问题。

发现了引导亡灵前往深渊的冥蛾，准备以此为指引前往深渊，却遭遇恶魔骚扰。

战斗过后，失去冥蛾踪迹，西格莉德运用时间魔法带领妮蔻拉丝继续追踪。
#### key 1034

深渊入口近在咫尺，却遭守护者锡蒙利拦截，双方发生冲突。

锡蒙利实力强劲，西格莉德与妮蔻拉丝难以与其抗衡。

然而一只冥蛾的出现，却改变了守护者的想法。
#### key 1035

进入深渊，大批冥蛾向求助发起求助，权衡之下，二人决定前去帮助冥蛾的主人——亡灵引渡人。

驱散一批低等恶魔后，亡灵引渡人盖德尔之魂寄宿于其上的引魂法杖，出现在了魔女们的面前。
#### key 1036

盖德尔与魔女进行一番交流，并在谈判后达成协议——由魔女带法杖前往冥河畔，而他则将引魂法杖给予二人作为报酬。

前往冥河途中遇到亡灵求救，西格莉德本欲置之不理，妮蔻拉丝却突然上前欲救下亡灵。
#### key 1037

大批恶魔卷土重来，魔女与亡灵身处险地。

危急时刻，妮蔻拉丝向盖德尔询问万全之法，西格莉德本想阻止，却在恍惚之间被妮蔻拉丝拿走引魂法杖，借由盖德尔所传魔咒，妮蔻拉丝成功施展秘术。

然而危机刚刚完结，新的状况接踵而至。
#### key 1038

西格莉德知晓妮蔻拉丝对其有所隐瞒。

为阻止妮蔻拉丝的决定，西格莉德带着剩下的灵魂碎片离开了深渊。

而妮蔻拉丝选择接任亡灵引渡人一职，只因她早已知晓真相，并作出了最后的抉择。
#### key 1041

菲尔斯醒来发现被困在天狱中，他依稀想起昏迷前听到一段对话，似乎在谋划着什么。

此事必须要立即向泰兰达尔神使长汇报，眼下的结界有些眼熟，情急之下先打破结界逃出去再说。
#### key 1042

打破阵法，菲尔斯遇到了巡逻的神使。

菲尔斯询问这里是哪里，结果神使告诉菲尔斯身犯谋杀同僚之罪，让他乖乖回去等待审判。

菲尔斯要求见泰兰达尔，神使不肯于是开战。
#### key 1043

打败了神使后，菲尔斯决定找其他人问问。

遇到了基露卜，从基露卜口中得知扎迦利已经判天，还认为自己是扎迦利的同党，解释不清只能开战。
#### key 1044

正要离开天狱却遇到了本该看守庄严神殿的利卫。

利卫声称他守在此处，奉劝菲尔斯乖乖返回天狱等待审判。
#### key 1045

遇到一个叛变神使亨利克，误把菲尔斯当做队友，菲尔斯将错就错套出扎迦利所在。

亨利克战败，消散之前表示他只是想要自由。
#### key 1046

前往战场途中遭遇该阿法阻拦，菲尔斯好言相劝此刻该共同御敌，但该阿法坚持奉命看守分割战场，决不能让任何人再去支援。

菲尔斯见谈不拢只能开打。
#### key 1047

竟连神使学院的老师欧诺弥亚都背叛了神庭，欧诺弥亚却表示自己是追随自己信仰而战，认为逻各斯专制无情，扎迦利才能带来真正的信仰之光。

两人各执立场无法相互说服，开战。

战后欧诺弥亚却表示，他绝对无法越过接下来会遇到的那个人。
#### key 1048

菲尔斯回头，看到了最熟悉的弟弟亚尔维斯，没想到他也归顺了扎迦利。

亚尔维斯控诉从小到大在神庭受到的不公平待遇，只有扎迦利让他看到了无上的自由与荣耀。

当亲情与信仰无法两全，菲尔斯该如何抉择？
